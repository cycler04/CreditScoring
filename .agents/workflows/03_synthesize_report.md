# Tổng hợp và viết báo cáo nghiên cứu

## Khi dùng

Dùng khi cần gom paper note, log thử nghiệm, code finding hoặc nhiều nguồn thành
báo cáo, overview, key finding, decision memo hay cập nhật tiến độ.

## Quy trình

1. Chốt audience, câu hỏi quyết định và độ sâu.
2. Lập inventory nguồn; loại nguồn trùng, cũ hoặc không truy vết được.
3. Chuẩn hóa thuật ngữ và phạm vi so sánh. Không so metric khác dataset/protocol
   như thể cùng điều kiện.
4. Gom theo claim/chủ đề thay vì tóm tắt tuần tự từng nguồn.
5. Gắn mỗi kết luận với paper, code location hoặc experiment evidence.
6. Nêu rõ mâu thuẫn giữa nguồn và giải thích khả dĩ; không ép thành đồng thuận.
7. Tách current evidence, inference, recommendation và open questions.
8. Soát lại tính tái lập, giới hạn và điều kiện khiến khuyến nghị thay đổi.

## Cấu trúc mặc định

1. Executive summary.
2. Câu hỏi và phạm vi.
3. Evidence và findings.
4. So sánh/đánh đổi.
5. Giới hạn và rủi ro.
6. Khuyến nghị ưu tiên.
7. Next experiments.
8. Sources/artifacts.
