# User preferences

- Dùng Codex trong workspace này.
- Muốn agent chủ động khảo sát, triển khai và kiểm tra thay vì hỏi các câu có thể tự trả
  lời từ repository.
- Ưu tiên giao tiếp tiếng Việt, ngắn gọn và có bằng chứng.
- Hỏi trước commit, push, xóa dữ liệu khó phục hồi hoặc hành động bên ngoài workspace.
