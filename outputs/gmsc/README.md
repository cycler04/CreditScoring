# Outputs

Artefact sinh từ pipeline:

- `eda/`: bảng và biểu đồ EDA.
- `models/metrics/`: bảng metric và biểu đồ ROC-AUC, Gini, KS.
- `models/`: fitted model, prediction và feature importance artifact.
- `scorecard/`: WoE/IV, scorecard và PSI.

Các artefact sinh tự động không được commit vào source control.
